# Текущее состояние

Снимок: v0.2.20, 2026-10-12. Исходный Sites commit `dc62016b0dc519620a83bef3b58f0f860ae7bcc7`; резервный GitHub commit `5df174e45323bc4a9d2299dc16c80bd964e51c52`.

Это описание реализованных правил, не сохранение конкретного игрока. Число людей/ресурсов/бункеров на пользовательском устройстве неизвестно. Данные игроков не извлекались и в репозиторий не загружались.

- Новая кампания: один основанный «Убежище 07», отдельные локальные экономики; до 12 бункеров.
- Ресурсы интерфейса: пища, вода, энергия, материалы, металл, топливо, инструменты, руда. Водоносные слои дают сырую подземную воду, насос преобразует её в питьевую. Залежи конечны. Склад добавляет 600 ёмкости на ресурс к базовым 250.
- Строительство, раскопки, разборка, лестницы, операторы, рабочие приоритеты, усталость, здоровье, отдых, исследовательское развитие и логистика реализованы.
- Тоннель требует исследования всех 600 клеток текущего и завершения исследования уже открытых бункеров. Нужен достижимый край, один свободный здоровый строитель, 40 материалов, 12 металла, 2 инструмента. Новый проект total=80; импорт поддерживает прежние total=160. Только один активный проект.
- По завершении соседний бункер появляется на мини-карте. Он состоит из неизвестной породы и входа. Переход для осмотра не означает основание.
- Основание: 5 переселенцев, минимум 5 оставшихся; комплект 240 материалов, 90 металла, 120 пищи, 150 воды, 100 топлива, 15 инструментов. Перевозка занимает время.
- Автономное управление поселениями, отдельные запасы, перевозки и общее знание исследований уже есть. Общая атомная энергосеть пока отсутствует.
- Золото, уран, ядерные производственные цепочки и специальный третий бункер не реализованы. Обычные дополнительные бункеры возможны по текущим правилам.

## Известные проблемы

A: метка/эффекты проходки могут перекрывать персонажа. Рабочий уже действительно назначается и идёт к краю; дорабатывать визуализацию существующего процесса.

B: `app.js`, начало `click(p)`: ранний return для body.city-only запрещает все действия на карте. При скрытии нужно сохранить выбранный tool и разрешить команды canvas. Текущий перенос намеренно сохраняет v0.2.20 без исправления игрового поведения.

Импорт JSON заменяет слот без диалога; ошибки загрузки требуют внимания. До импорта экспортировать оба мира. Старые миграции v15/v17/v18 могут очищать прежние тестовые бункеры, если отсутствуют флаги. Новый код переноса их не запускает и не изменяет; будущему разработчику изучить их до работы со старыми сохранениями.
