# Архитектура v0.2.20

Чистый JavaScript ES modules, Canvas 2D и DOM/CSS. Нет framework, сервера, npm-зависимостей, CDN, внешних шрифтов, ключей или загружаемых изображений. Ресурсы опубликованной игры — процедурная графика в коде и inline SVG. Отдельные старые визуальные прототипы не входят в эту рабочую сборку.

| Файл | Ответственность и точки входа |
|---|---|
| `dist/engine.js` | `createWorld`, `step`, `command`, `BUILD`, задания строительства/раскопок/разборки, pathfinding, жители, исследования, геология; `serialize`/`restore` и миграции местного мира |
| `dist/economy.js` | Производственные рецепты, ресурсы, складская ёмкость, операторы, доставка, топливо, электричество, предупреждения |
| `dist/campaign.js` | `createCampaign`, `stepCampaign`, `startTunnel`, `nextTunnelEntrance`, `finishProject`, `foundBunker`; бункеры, переселенцы, грузы, межбункерные связи; `serializeCampaign`/`restoreCampaign` |
| `dist/render.js` | Отрисовка комнат, породы, людей, `residentPose`, `drawTunnelWork`, камера и локальная карта |
| `dist/campaign-render.js` | `drawCampaignOverview`, `campaignHit`: мини-карта и выбор бункера |
| `dist/app.js` | Главный цикл, UI, жесты, `click`, выбранный `tool`, `cityMode`, тоннельная кнопка, сохранение/экспорт/импорт |
| `dist/storage.js` | IndexedDB, `saveWorld`, `loadWorld`, `prepareLoadedCampaign`, резервные копии миграций |
| `dist/index.html`, `dist/style.css` | DOM, окна и адаптивный HUD, скрытый интерфейс |
| `build-standalone.py` | Объединяет модули в фиксированном порядке и встраивает JS/CSS в один HTML |
| `.openai/hosting.json` | Только привязка старого Sites проекта к `dist`; не нужна GitHub Pages |
| `.github/workflows/*` | Проверки веток/PR и отдельная ручная публикация Pages |

`app.js` хранит campaign и ссылку `s` на world активного бункера. Campaign включает bunkers, links, projects, shipments, активный ID и время. Каждый бункер владеет world, людьми и запасами. `stepCampaign` продвигает связанные системы, UI перерисовывает состояние; переключение камеры не создаёт другой демонстрационный мир.

Внутренняя сетка движка унаследована 64×40; активные границы каждого нового бункера 30×20 (600 клеток). Не заменять индексацию сетки размером локальных границ. Геология детерминирована seed. Размер клетки рендера TW=160, TH=112.

Тоннель — проект кампании. Ресурсы списываются в начале; свободный здоровый житель получает campaignProject, ищет путь к edge, прогресс идёт по фактическому прибытию и работе. После завершения создаются соседний world и link; новый бункер ещё требует основания. Длительность — условные единицы труда, не обещание точного количества секунд.

Сохранение: местный VERSION=14, campaignVersion=1. JSON проходит restore/валидацию; storage запускает исторические миграции. IndexedDB `last-city`, store `world`, key `last-city-v1`. Формат, миграционные флаги и ключ нельзя менять без совместимой миграции и тестов. Код работает только пока выполняется вкладка, ОС может замораживать фоновую вкладку.

Сборщик удаляет imports/exports простым текстовым преобразованием. При изменении формы модулей проверять модульный сайт и автономный HTML; не считать сложный bundling автоматически поддержанным.
