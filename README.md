# LAST CITY: UNDERGROUND

Браузерная стратегия о строительстве подземных поселений. Сохранённая игровая версия **v0.2.20**; перенос инфраструктуры не меняет игровой код.

- Основная ветка: `main`. Неизменённый снимок: `backup/v0.2.20`, commit `5df174e45323bc4a9d2299dc16c80bd964e51c52`.
- Начало работы другого разработчика: [HANDOFF.md](HANDOFF.md).

## Запуск

Нужны Python 3 и Node.js 22 или новее для проверок. Зависимостей npm нет, `npm install` не нужен.

```sh
git clone https://github.com/GeshaAI/last-city-underground.git
cd last-city-underground
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Для Android можно использовать опубликованный HTTPS-сайт или адрес компьютера в одной локальной сети. Не открывайте модульный `dist/index.html` через `file://`.

```sh
npm test
npm run check
npm run build
```

`dist/` — настоящие редактируемые исходники и готовый статический сайт, а не результат компиляции. Старый сборщик создаёт автономный `LAST_CITY_v0.1.html`: имя историческое, внутри v0.2.20. Его тоже предпочтительно отдавать через HTTP/HTTPS для предсказуемых сохранений.

## Управление

«Стройка» выбирает здание; нажатие на клетку отдаёт приказ. Раскопки открывают породу. Лестницы соединяют этажи. Перетаскивание перемещает камеру; кнопки +/− и жест масштабирования меняют масштаб. «Жители» — занятость и приоритеты; «Наука» — исследования; «Поселения» — сеть бункеров. Пауза и 1×/3×/8× управляют симуляцией. Мини-карта переключает бункеры. После изучения 600 клеток и выполнения условий доступен тоннель. «Только город»/закрытие мини-карты скрывает HUD; отдельная кнопка возвращает интерфейс.

**Известно:** в v0.2.20 скрытый интерфейс блокирует строительные касания. Это задача B, а не исправление в этом переносе.

## Сохранения

«Мир» → экспорт JSON, импорт JSON, сохранить/загрузить. Автосохранение в IndexedDB этого браузера и origin примерно каждые 20 секунд. Серверных аккаунтов и облачной синхронизации нет. Перед импортом обязательно экспортируйте текущий мир: импорт заменяет слот без отдельного подтверждения. См. ограничения и перенос в [HANDOFF.md](HANDOFF.md).

## Публикация

GitHub Pages workflow вручную запускается на `main` после проверок; публикует только `dist/`. В Settings → Pages должен быть выбран GitHub Actions. Новый адрес не переносит старые сохранения автоматически. Исходный сайт Sites не обновляется этим workflow. Платные сервисы и API-ключи для игры не нужны. Стандартные Linux runners; не включайте платные runners/услуги.
